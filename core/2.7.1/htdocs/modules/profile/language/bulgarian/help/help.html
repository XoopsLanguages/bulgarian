Помощ: Профил

-----Помощно съдържание ----------

ОПИСАНИЕ

Модулът Профил е за управление на персонализирани полета на потребителския профил.

ИНСТАЛИРАНЕ/ДЕИНСТАЛИРАНЕ

Не са необходими специални мерки, следвайте стандартния процес на инсталиране – извлечете папката /profile в директорията ../modules. Инсталирайте модула през Admin -> System Module -> Modules.

Подробни инструкции за инсталиране на модули можете да намерите в Ръководство за работа на XOOPS

ИНСТРУКЦИИ ЗА ЕКСПЛОАТАЦИЯ

За да настроите този модул трябва да:

  • Конфигурирайте вашите предпочитания за модула (вижте „Предпочитания“) и по желание блока на профила, ако възнамерявате да го използвате (вижте „Блокове“).
  • Редактирайте съществуващи категории или добавете нови.
  • Редактирайте съществуващи полета или добавете нови. Тук можете да посочите кои полета в коя категория ще бъдат видими и дали ще бъдат видими по време на регистрация на потребител.
  • Определете реда на стъпките за регистрация.
  • И накрая, можете да зададете разрешения за отделни полета - кои могат да се редактират, кои могат да се търсят.

Антиспам мерки

За да минимизирате спам регистрациите, направете следното:

  • отидете на модула Protector в Admin, отидете на Preferences и след това в долната част, на тази опция: „Спрете спама във форума“ Проверява POST данните срещу спамери, регистрирани в базата данни на www.stopforumspam.com.
    Задайте го на "Забрана на IP (без ограничение)"

  • в /class/captcha/config.php се уверете, че режимът е зададен като "текст":

    return $config = array(
    'disabled' => false, // Деактивиране на CAPTCHA
    'mode' => 'text', // режим по подразбиране, можете да изберете 'text', 'image', 'recaptcha' (изисква api ключ)
    'name' => 'xoopscaptcha', // captcha име
    'skipmember' => true, // Пропускане на CAPTCHA проверката за членове
    'maxattempts' => 10, // Максимален брой опити за всяка сесия
    );

  • В модула Профил отидете на Администратор и в основната стъпка, намираща се на:
    /modules/profile/admin/step.php?id=1
    задайте "Запазване след спиране" на "Не"


  • В предпочитанията на профила задайте опцията „Използване на Captcha след втората стъпка на регистрация“ на „Да“ (това е по подразбиране)
